## 🌟 What is Portfolio V3?

**Rumman's Portfolio V3** is a state-of-the-art full-stack personal portfolio application designed to deliver an unforgettable, recruiter-ready visual experience while maintaining robust, enterprise-grade backend architecture. 

Moving beyond traditional static portfolio templates, **V3** introduces a dynamic, highly interactive environment where content is managed in real-time via a secure, custom-built Admin Portal.

---

## ✨ Core Design Philosophy: The "Liquid Glass" Aesthetic

At the heart of Portfolio V3 lies the **Liquid Glass** design system:
- 🎨 **Frosted Glassmorphism**: Multi-layered translucent cards with dynamic backdrop blur (`backdrop-blur-xl`), delicate borders (`border-white/10`), and soft ambient glowing shadows.
- ⚡ **GSAP & ScrollTrigger Powerhouse**: Buttery-smooth parallax scrolling, magnetic button micro-interactions, cascading text reveals, and responsive entrance animations.
- 📐 **Adaptive Bento Grids**: Modern, asymmetric layout grids that intelligently reflow across desktops, tablets, and mobile screens to showcase projects and technical skills without visual clutter.

## 🚀 Quick Start Highlights

```bash
# 1. Clone the repository
git clone https://github.com/rumman2004/Portfolio-v3.git

# 2. Start the Backend Server (Port 5000)
cd "Portfolio V3/server" && npm run dev

# 3. Start the Frontend Application (Port 5173)
cd "../client" && npm run dev
```
